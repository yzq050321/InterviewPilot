
# Python 后端开发面试知识库

## Python GIL

GIL 是 CPython 解释器中的全局解释器锁。
在常规 CPython 构建中，同一进程内通常只有一个线程能同时执行 Python 字节码。

GIL 对 CPU 密集型多线程程序可能产生性能限制。
对于 I/O 密集型任务，多线程仍然可以提高程序的并发处理能力。

常见面试问题：
1. 什么是 GIL？
2. GIL 对 Python 多线程有什么影响？
3. CPU 密集型任务为什么可以考虑多进程？

## Python 同步与异步

同步函数使用 def 定义。
异步协程函数使用 async def 定义。

在异步编程中，await 可以等待支持异步协议的操作，
让事件循环有机会执行其他任务。

async def 不会自动把同步阻塞操作转换成异步操作。

常见面试问题：
1. def 和 async def 有什么区别？
2. 为什么不能在异步路由中直接调用 time.sleep()？
3. 什么情况下适合使用异步编程？

## FastAPI 依赖注入

FastAPI 使用 Depends 实现依赖注入。

依赖注入可以用于：
- 获取数据库 Session
- 验证用户身份
- 复用公共请求逻辑

使用 yield 的依赖函数可以在请求处理前创建资源，
并在依赖退出时清理资源。

常见面试问题：
1. FastAPI 的 Depends 有什么作用？
2. 为什么数据库 Session 通常通过依赖注入获取？
3. yield 和 return 在依赖函数中有什么区别？

## MySQL 数据库事务

数据库事务通常具有 ACID 特性：
原子性、一致性、隔离性、持久性。

在 SQLAlchemy 中：
- add() 将对象加入 Session
- flush() 将待执行的 SQL 发送给数据库，但不提交事务
- commit() 提交事务
- rollback() 回滚尚未提交的事务

常见面试问题：
1. 什么是数据库事务？
2. flush() 和 commit() 有什么区别？
3. 为什么需要 rollback()？

## HTTP 状态码

200 表示请求成功。
201 表示资源创建成功。
400 表示请求有问题。
401 表示请求未通过身份认证。
404 表示资源不存在。
422 常用于 FastAPI 请求数据验证失败。
500 表示服务器内部错误。
502 表示网关或代理收到无效的上游响应。
504 表示网关或代理等待上游响应超时。

常见面试问题：
1. 400 和 422 有什么区别？
2. 502 和 504 有什么区别？
3. REST API 应该如何选择状态码？
